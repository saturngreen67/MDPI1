# PRI Assessment Report

## Scope and method

This report assesses the provided climate-related risk drivers using the supplied PRI data table only. Risks are presented in descending order of PRI. Where the table provides a dash or no relevant hazard variation, it is treated as not applicable; however, no such case appears in the supplied data. EI is taken as provided in the table, and where economic asset valuation is unavailable in general practice, EI = 3 would be the conservative default; this default was not required here because EI values are already specified.

PRI is interpreted as derived from HI × EI × VI and normalised to a 0–4 scale, consistent with the supplied table values.
