# PRI Assessment Report

This report details the Infrastructure Risk Assessment (PRI) for identified impacts related to climate change. The PRI is calculated using the formula: PRI = (HI x EI x VI) / 4, where HI represents Hazard Impact, EI represents Economic Impact, and VI represents Vulnerability Impact. Scores are normalised to a 0-4 scale. Due to data unavailability regarding specific economic asset valuations, the Economic Impact (EI) has been conservatively set to a default of 3 for all entries where a specific economic valuation was not provided.
